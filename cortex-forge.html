Machine Learning Core — our internal framework for harnessing the full ML acceleration stack on Jetson: Ampere GPU (2048 CUDA + 64 Tensor Cores), dual NVDLA v2.0, and PVA v2.0. We use this as our starting point for every project that needs model inference, task scheduling, or real-time accelerator monitoring.

Overview

Cortex Forge is one of the five building blocks we've extracted from our internal Jetson projects — battle-tested across TX1, TX2, Xavier, Orin, and Thor since 2015. It's the ML acceleration framework we reach for first when starting a new project. The architecture follows our standard three-tier pattern: a Linux kernel driver for direct NVDLA/PVA access, a C++17 gRPC server for model management and inference over the network, and a PySide6 desktop GUI for real-time monitoring and control.

  • GPU-Accelerated Inference — Leverages CUDA and TensorRT for real-time model deployment on the Ampere GPU, with support for quantization, batching, and latency tuning at the edge.
  • Multi-Accelerator Support — Schedules inference tasks across GPU, NVDLA 0, NVDLA 1, and PVA simultaneously, demonstrating concurrent AI workloads on a single device.
  • Real-Time Monitoring — Exposes per-accelerator utilization, temperature, memory usage, and inference latency metrics through gRPC streaming endpoints.
  • Fault Detection & Recovery — Implements task timeout, cancellation, and error reporting for inference workloads, with automatic recovery from accelerator hangs.
  • Secure Model Updates — Supports loading and unloading models at runtime without server restart, enabling field-update patterns for OTA-style model deployment.
  • Sensor Fusion Ready — Server-side design anticipates combining model output with other sensor streams (camera, audio) for multi-modal inference pipelines.

Architecture

Kernel Driver

C · Linux Kernel Module

The cortex-forge-driver is a Linux kernel module that provides direct userspace access to the NVDLA v2.0 and PVA v2.0 hardware accelerators through a character device interface. It implements a complete task management system with allocation, submission, query, and cancellation of inference tasks across all three accelerator types.

  • Char device interface with unified ioctl protocol for task submission, query, and cancellation
  • Kernel worker threads per accelerator with configurable timeouts and priority scheduling
  • Platform abstraction layer for SoC-specific register maps and clock/reset management
  • Userspace C library (libcortex-forge) wrapping the ioctl interface for application developers
  • Comprehensive test suite with multi-threaded stress testing and edge case coverage
  • sysfs attributes for accelerator status and debugfs interface for diagnostics

gRPC Server

C++17 · CMake · gRPC · Protobuf

The cortex-forge-server is a C++17 gRPC daemon that exposes model management and inference capabilities over the network. It provides a clean service-oriented API for loading/unloading models, running synchronous and streaming inference, and monitoring accelerator metrics in real time.

  • 9 RPCs across model management, inference, monitoring, and health check categories
  • Abstract InferenceEngine interface with stub implementation for development and TensorRT backend for production
  • AcceleratorManager with auto-selection logic for optimal accelerator targeting
  • MetricsCollector tracking P99 latency, throughput, and per-accelerator utilization
  • Server-streaming endpoints for real-time metrics and inference result streaming
  • Catch2 unit tests with 20+ test cases covering all service operations

Desktop GUI

Python · PySide6 · gRPC

The cortex-forge-gui is a cross-platform PySide6 desktop application that provides real-time monitoring and control of the ML inference pipeline. It features a macOS-inspired design with a complete menu bar, sidebar navigation, and big elegant button boxes for common actions.

  • macOS-style menu bar with File, Edit, View, Tools, and Help menus with keyboard shortcuts
  • Sidebar navigation with Dashboard, Controls, and Settings pages
  • Real-time accelerator metrics display with GPU, DLA0, DLA1, and PVA utilization gauges
  • Model management interface for loading, unloading, and configuring inference models
  • BigButtonBox widgets for primary actions with large rounded buttons and hover states
  • Light theme with white backgrounds, blue accent (#1976D2), and dark text (#212121)
