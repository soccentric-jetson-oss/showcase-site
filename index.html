Building Blocks for Jetson

We've been building on NVIDIA Jetson since the TX1 in 2015 — over a dozen projects across TX1, TX2, Xavier, Orin, and Thor. This is our attempt to open-source some of the frameworks and building blocks we use internally to kickstart every new project. Sharing what we know helps us grow too. Hope it does the same for you.

Five Frameworks

Each framework serves a different aspect of Jetson development. We use these as our starting point for every new project.

Cortex Forge

Machine Learning Core

Harnesses the Ampere GPU (CUDA + Tensor Cores), dual NVDLA v2.0, and PVA v2.0 for model inference, task scheduling, and real-time accelerator monitoring. Our starting point for every ML project on Jetson.

NVDLA PVA CUDA TensorRT gRPC

Iris Flow

Vision Pipelining Core

Drives the 16-lane MIPI CSI-2 interface, ISP for raw Bayer sensors up to 24MP, and multi-stream handling for up to 6 cameras. Used across dozens of vision projects — from thermal imaging to autonomous navigation.

MIPI CSI-2 ISP GStreamer V4L2

Reel Forge

Video Processing Core

Exploits hardware video encode (4×4K60, AV1) and decode (8×4K60) plus the VIC for 16-surface blending, lens correction, and scaling. Every video project since TX1 started here.

H.264 H.265 AV1 VIC

Nexus Bus

Peripheral Access Core

Unifies GPIO (40-pin), 8 I2C, 3 SPI, 4 UART, and 2 CAN interfaces into a single character device and gRPC API. Built because every project needs peripherals and we got tired of rewriting the same boilerplate.

GPIO I2C SPI UART CAN

Volt Guard

Power Management Core

Controls the 15W–60W power envelope, dynamic mode switching, PMIC voltage rail sequencing, and real-time telemetry. Essential for every deployment where power budgets actually matter.

PMIC Power Modes Telemetry
