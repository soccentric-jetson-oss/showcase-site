Cortex Forge

Machine Learning Core — harnesses the Ampere GPU (CUDA + Tensor Cores), dual NVDLA v2.0 deep learning accelerators, and PVA v2.0 for model inference, task scheduling, and real-time accelerator monitoring.

NVDLA PVA CUDA TensorRT gRPC

Iris Flow

Vision Pipelining Core — drives the 16-lane MIPI CSI-2 camera interface, Image Signal Processor (ISP) for raw Bayer sensors up to 24MP, and multi-stream camera handling with real-time ISP tuning and GStreamer pipeline integration.

MIPI CSI-2 ISP GStreamer V4L2

Reel Forge

Video Processing Core — exploits hardware video encode (4×4K60, AV1) and decode (8×4K60) blocks plus the Video Image Compositor (VIC) for 16-surface blending, lens distortion correction, scaling, and deinterlacing.

H.264 H.265 AV1 VIC RTSP

Nexus Bus

Peripheral Access Core — unifies GPIO (40-pin header), 8 I2C controllers, 3 SPI controllers, 4 UART ports, and 2 CAN bus interfaces through a single character device and gRPC interface with bus-level fault handling.

GPIO I2C SPI UART CAN

Volt Guard

Power Management Core — controls the configurable 15W–60W power envelope, dynamic power mode switching, PMIC-level voltage rail sequencing, and real-time telemetry for voltage, current, temperature, and power draw.

PMIC Power Modes Telemetry 15-60W

Built on NVIDIA Jetson AGX Orin · Open source · MIT & GPL-2.0 licensed
