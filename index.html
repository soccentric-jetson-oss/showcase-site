Building Blocks
for Jetson

We've been building on NVIDIA Jetson since the TX1 in 2015 — over a dozen projects across TX1, TX2, Xavier, Orin, and Thor. This is our attempt to open-source some of the frameworks and building blocks we use internally to kickstart every new project. Sharing what we know helps us grow too. Hope it does the same for you.

Cortex Forge

Machine Learning Core — harnesses the Ampere GPU (CUDA + Tensor Cores), dual NVDLA v2.0 deep learning accelerators, and PVA v2.0 for model inference, task scheduling, and real-time accelerator monitoring.

NVDLA PVA CUDA TensorRT gRPC

Iris Flow

Vision Pipelining Core — drives the 16-lane MIPI CSI-2 camera interface, Image Signal Processor (ISP) for raw Bayer sensors up to 24MP, and multi-stream camera handling with real-time ISP tuning.

MIPI CSI-2 ISP GStreamer V4L2

Reel Forge

Video Processing Core — exploits hardware video encode (4×4K60, AV1) and decode (8×4K60) blocks plus the Video Image Compositor (VIC) for 16-surface blending, lens distortion correction, and scaling.

H.264 H.265 AV1 VIC

Nexus Bus

Peripheral Access Core — unifies GPIO (40-pin header), 8 I2C controllers, 3 SPI controllers, 4 UART ports, and 2 CAN bus interfaces through a single character device and gRPC interface.

GPIO I2C SPI UART CAN

Volt Guard

Power Management Core — controls the configurable 15W–60W power envelope, dynamic power mode switching, PMIC-level voltage rail sequencing, and real-time telemetry for voltage, current, and temperature.

PMIC Power Modes Telemetry
