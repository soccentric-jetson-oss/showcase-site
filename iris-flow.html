Overview

Iris Flow is one of the five building blocks we've extracted from our internal Jetson projects — refined over years of real-world use across TX1, TX2, Xavier, Orin, and Thor. It's the vision pipeline we bootstrap every camera project with. The architecture follows our standard three-tier pattern: a Linux kernel driver for direct MIPI CSI-2 and ISP access, a C++17 gRPC server for frame processing and pipeline configuration, and a PySide6 desktop GUI for live preview and ISP tuning.

  • Multi-Stream Camera — Supports up to 6 simultaneous camera streams over the 16-lane MIPI CSI-2 interface, with independent resolution and format configuration per stream.
  • Real-Time ISP Tuning — Exposes brightness, contrast, saturation, and sharpness controls through gRPC, with immediate application to the hardware ISP pipeline.
  • GStreamer Integration — Server-side pipeline construction using GStreamer for capture, encoding, processing, storage, and streaming with RTSP and WebRTC output support.
  • Low-Latency Design — Architecture optimized for real-time video delivery with sub-frame latency, including frame dropping detection and automatic stream recovery.
  • Thermal Camera Support — Architecture considers non-visible-spectrum camera integration (thermal, IR) for specialized imaging use cases beyond standard sensors.
  • Camera Tuning Pipeline — Calibration, color processing, exposure control, and image-quality tuning treated as first-class concerns in the pipeline design.

Architecture

Kernel Driver

C · Linux Kernel Module

The iris-flow-driver is a Linux kernel module that provides direct userspace access to the MIPI CSI-2 and ISP hardware through a character device interface. It implements a complete camera management system with sensor configuration, frame capture, and ISP parameter control.

  • Char device interface for camera sensor configuration, frame capture, and ISP parameter control
  • V4L2-compatible interface for standard camera integration with media controller support
  • Multi-stream support for up to 6 simultaneous camera inputs with independent configuration
  • Userspace C library (libiris-flow) wrapping the ioctl interface for application developers
  • Device tree overlay for IMX708 sensor module with compatible string and pinmux configuration
  • sysfs attributes for sensor status and debugfs interface for ISP register diagnostics

gRPC Server

C++17 · CMake · gRPC · Protobuf

The iris-flow-server is a C++17 gRPC daemon that exposes camera stream management and ISP tuning capabilities over the network. It provides a clean service-oriented API for configuring streams, capturing frames, and adjusting ISP parameters in real time.

  • 8 RPCs across stream control, frame capture, ISP tuning, and health check categories
  • GStreamer-based pipeline construction for capture, encode, process, store, and stream operations
  • Server-streaming endpoint for real-time frame delivery at configurable frame rates
  • Per-stage latency instrumentation for capture, ISP processing, and frame delivery timing
  • FFmpeg integration for hardware-accelerated encoding and streaming output
  • Catch2 unit tests with edge case coverage for stream configuration and ISP parameter validation

Desktop GUI

Python · PySide6 · gRPC

The iris-flow-gui is a cross-platform PySide6 desktop application that provides real-time camera preview and ISP tuning controls. It features a macOS-inspired design with a complete menu bar, sidebar navigation, and big elegant button boxes for common actions.

  • macOS-style menu bar with File, Edit, View, Tools, and Help menus with keyboard shortcuts
  • Sidebar navigation with Dashboard, Controls, and Settings pages
  • Live camera preview with real-time frame rate and resolution display
  • ISP tuning panel with brightness, contrast, saturation, and sharpness sliders for real-time adjustment
  • BigButtonBox widgets for primary actions with large rounded buttons and hover states
  • Light theme with white backgrounds, blue accent (#1976D2), and dark text (#212121)
