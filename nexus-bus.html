Overview

Nexus Bus is an open-source showcase project that demonstrates full exploitation of the NVIDIA Jetson AGX Orin's peripheral and bus I/O capabilities. The project targets the AGX Orin as its foundational hardware and is composed of three independent sub-projects, each living in its own GitHub repository. The architecture follows a clean three-tier pattern: a Linux kernel driver provides direct hardware access to GPIO, I2C, SPI, UART, and CAN controllers, a C++17 gRPC server exposes unified peripheral access over the network, and a cross-platform PySide6 desktop GUI delivers real-time bus monitoring and control.

  • Unified Peripheral Interface — Single character device interface for all bus protocols with consistent read/write semantics and error handling.
  • Multi-Protocol Support — Native support for GPIO, I2C, SPI, UART, and CAN with protocol-specific optimizations and hardware timing control.
  • Real-Time Bus Monitoring — Exposes per-bus utilization, error rates, and transaction latency metrics through gRPC streaming endpoints.
  • Remote Peripheral Access — Full gRPC API for reading/writing GPIO pins, I2C/SPI transactions, UART data, and CAN frames over the network.
  • Fault Detection & Recovery — Implements bus timeout detection, automatic retry, and error reporting for all peripheral transactions.
  • Sensor Network Ready — Architecture designed for connecting and managing distributed sensor networks through the unified bus interface.

Architecture

Kernel Driver

C · Linux Kernel Module

The nexus-bus-driver is a Linux kernel module that provides direct userspace access to the GPIO, I2C, SPI, UART, and CAN controllers through a unified character device interface. It implements a complete peripheral management system with transaction queuing, bus arbitration, and hardware-level timing control.

  • Unified char device interface with protocol-agnostic ioctl for all bus transactions
  • Kernel worker threads per bus controller with configurable timeouts and priority scheduling
  • Platform abstraction layer for SoC-specific register maps and clock/reset management
  • Userspace C library (libnexus-bus) wrapping the ioctl interface for application developers
  • Comprehensive test suite with multi-bus stress testing and edge case coverage
  • sysfs attributes for bus status and debugfs interface for transaction diagnostics

gRPC Server

C++17 · CMake · gRPC · Protobuf

The nexus-bus-server is a C++17 gRPC daemon that exposes unified peripheral access over the network. It provides a clean service-oriented API for GPIO control, I2C/SPI transactions, UART communication, and CAN bus messaging with real-time monitoring.

  • 12 RPCs across GPIO, I2C, SPI, UART, CAN, and health check categories
  • Abstract BusInterface with per-protocol implementations for optimal hardware utilization
  • TransactionManager with automatic bus arbitration and conflict resolution
  • MetricsCollector tracking per-bus throughput, latency, and error rates
  • Server-streaming endpoints for real-time bus monitoring and event notifications
  • Catch2 unit tests with 25+ test cases covering all service operations

Desktop GUI

Python · PySide6 · gRPC

The nexus-bus-gui is a cross-platform PySide6 desktop application that provides real-time bus monitoring and peripheral control. It features a macOS-inspired design with a complete menu bar, sidebar navigation, and big elegant button boxes for common actions.

  • macOS-style menu bar with File, Edit, View, Tools, and Help menus with keyboard shortcuts
  • Sidebar navigation with Dashboard, Controls, and Settings pages
  • Real-time bus activity display with per-protocol transaction logs and error visualization
  • GPIO pin control panel with digital read/write and PWM configuration
  • BigButtonBox widgets for primary actions with large rounded buttons and hover states
  • Light theme with white backgrounds, blue accent (#1976D2), and dark text (#212121)
