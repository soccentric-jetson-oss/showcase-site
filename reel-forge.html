Reel Forge

Video Processing Core — our internal framework for hardware-accelerated video on Jetson. Wraps the encode/decode blocks (4×4K60 encode, 8×4K60 decode, AV1) and VIC compositor for 16-surface blending, lens correction, and scaling. Every video project we've shipped since TX1 started here.

Overview

Reel Forge is one of the five building blocks we've extracted from our internal Jetson projects — proven across TX1, TX2, Xavier, Orin, and Thor since 2015. It's the video processing framework we start with whenever a project needs transcoding, compositing, or streaming. The architecture follows our standard three-tier pattern: a Linux kernel driver for direct VIC and codec access, a C++17 gRPC server for transcoding and compositing over the network, and a PySide6 desktop GUI for real-time video control.

  • Hardware-Accelerated Transcoding — Leverages the dedicated H.264, H.265, and AV1 encode/decode blocks for high-throughput video transcoding with minimal CPU overhead.
  • Multi-Surface Compositing — Uses the VIC hardware for blending up to 16 video surfaces with alpha blending, chroma keying, and geometric transforms.
  • Lens Distortion Correction — Hardware-accelerated correction for wide-angle and fisheye lenses using the VIC's geometric processing pipeline.
  • Real-Time Streaming — Supports RTSP, WebRTC, and HLS output with sub-second latency for live video distribution.
  • Batch Processing — Queue-based transcoding engine for batch video processing with progress tracking and error recovery.
  • GPU-Accelerated Filters — CUDA-based video filters for real-time effects, color grading, and AI-powered video analysis.

Architecture

Kernel Driver

C · Linux Kernel Module

The reel-forge-driver is a Linux kernel module that provides direct userspace access to the VIC and video codec hardware through a character device interface. It implements a complete video processing management system with surface allocation, compositing, and encode/decode control.

  • Char device interface with unified ioctl protocol for VIC compositing and codec control
  • Kernel worker threads for video processing with configurable buffer management
  • Platform abstraction layer for SoC-specific VIC register maps and clock/reset management
  • Userspace C library (libreel-forge) wrapping the ioctl interface for application developers
  • Comprehensive test suite with multi-stream stress testing and edge case coverage
  • sysfs attributes for codec status and debugfs interface for VIC pipeline diagnostics

gRPC Server

C++17 · CMake · gRPC · Protobuf

The reel-forge-server is a C++17 gRPC daemon that exposes video transcoding and compositing capabilities over the network. It provides a clean service-oriented API for configuring encode/decode pipelines, managing compositing surfaces, and monitoring video processing metrics in real time.

  • 10 RPCs across transcoding, compositing, streaming, and health check categories
  • Abstract VideoPipeline interface with hardware and software backend implementations
  • SurfaceManager with automatic memory management for VIC compositing surfaces
  • MetricsCollector tracking throughput, latency, and per-codec utilization
  • Server-streaming endpoints for real-time transcoding progress and metrics
  • Catch2 unit tests with 20+ test cases covering all service operations

Desktop GUI

Python · PySide6 · gRPC

The reel-forge-gui is a cross-platform PySide6 desktop application that provides real-time video processing control and monitoring. It features a macOS-inspired design with a complete menu bar, sidebar navigation, and big elegant button boxes for common actions.

  • macOS-style menu bar with File, Edit, View, Tools, and Help menus with keyboard shortcuts
  • Sidebar navigation with Dashboard, Controls, and Settings pages
  • Real-time video preview with transcoding progress and quality metrics
  • Compositing workspace for arranging and blending multiple video surfaces
  • BigButtonBox widgets for primary actions with large rounded buttons and hover states
  • Light theme with white backgrounds, blue accent (#1976D2), and dark text (#212121)
