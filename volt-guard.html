Overview

Volt Guard is one of the five building blocks we've extracted from our internal Jetson projects — refined across TX1, TX2, Xavier, Orin, and Thor since 2015. It's the power management framework we use in every deployment where thermal and power constraints are critical. The architecture follows our standard three-tier pattern: a Linux kernel driver for direct PMIC and voltage rail access, a C++17 gRPC server for power configuration and telemetry, and a PySide6 desktop GUI for real-time power monitoring and control.

  • Dynamic Power Mode Switching — Programmatic control over the 15W–60W power envelope with seamless mode transitions and automatic thermal management.
  • PMIC-Level Voltage Control — Direct access to PMIC registers for voltage rail sequencing, ramp rate control, and power-good monitoring.
  • Real-Time Telemetry — Exposes voltage, current, power, and temperature readings from all PMIC rails through gRPC streaming endpoints.
  • Thermal Management — Automatic power throttling based on junction temperature with configurable thermal limits and alert thresholds.
  • Power Profiling — Built-in power profiling tools for measuring per-rail consumption under different workload scenarios.
  • Fault Detection & Recovery — Implements over-voltage, under-voltage, over-current, and over-temperature protection with automatic recovery sequences.

Architecture

Kernel Driver

C · Linux Kernel Module

The volt-guard-driver is a Linux kernel module that provides direct userspace access to the PMIC and voltage rail hardware through a character device interface. It implements a complete power management system with voltage rail control, telemetry collection, and fault detection.

  • Char device interface with unified ioctl protocol for PMIC control and telemetry access
  • Kernel worker threads for telemetry collection with configurable sampling rates
  • Platform abstraction layer for SoC-specific PMIC register maps and power sequencing
  • Userspace C library (libvolt-guard) wrapping the ioctl interface for application developers
  • Comprehensive test suite with power state transition testing and edge case coverage
  • sysfs attributes for power rail status and debugfs interface for PMIC register diagnostics

gRPC Server

C++17 · CMake · gRPC · Protobuf

The volt-guard-server is a C++17 gRPC daemon that exposes power management and telemetry capabilities over the network. It provides a clean service-oriented API for configuring power modes, reading telemetry, and monitoring power rail status in real time.

  • 9 RPCs across power mode control, telemetry, configuration, and health check categories
  • Abstract PowerManager interface with hardware and simulation backend implementations
  • TelemetryCollector with configurable sampling rates and historical data buffering
  • MetricsCollector tracking power consumption, efficiency, and thermal headroom
  • Server-streaming endpoints for real-time telemetry and alert notifications
  • Catch2 unit tests with 20+ test cases covering all service operations

Desktop GUI

Python · PySide6 · gRPC

The volt-guard-gui is a cross-platform PySide6 desktop application that provides real-time power monitoring and control. It features a macOS-inspired design with a complete menu bar, sidebar navigation, and big elegant button boxes for common actions.

  • macOS-style menu bar with File, Edit, View, Tools, and Help menus with keyboard shortcuts
  • Sidebar navigation with Dashboard, Controls, and Settings pages
  • Real-time power telemetry display with voltage, current, and temperature gauges
  • Power mode control panel for switching between 15W, 30W, and 60W modes
  • BigButtonBox widgets for primary actions with large rounded buttons and hover states
  • Light theme with white backgrounds, blue accent (#1976D2), and dark text (#212121)
